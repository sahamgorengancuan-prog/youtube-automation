# ADR-0009 — Commercial primaries, open-source as routed fallback/second-opinion
Status: accepted.
Context: the Diamond addendum specifies a large open-source stack; the operator directed that the PRIMARY stack stays OpenAI (story/TTS/transcription), BFL (images), and OpenRouter-hosted Qwen VL 32B (structural QC) + Gemini 2.5 Flash (editorial QC), with open models as fallback or second opinion — integrated where measurably more accurate.
Decision: a ServiceRegistry routes 13 services by tier (primary → fallback → second_opinion → objective → experimental). Commercial primaries are enabled by default; every open backend ships default_enabled=false and is additionally hard-blocked by the registry while its WEIGHT license status is NONCOMMERCIAL_ONLY / RESEARCH_ONLY / UNKNOWN_BLOCKED (license gate enforced in code, not docs). Promotion of an open backend requires: weight audit in model_weights.lock.json + benchmark win in its task category (benchmark.py) + deliberate enablement.
Alternatives: open-first with commercial fallback — rejected (operator direction; hosted 32B/Flash QC is the measured-quality baseline today). One universal model — rejected (correlated evaluation errors; §1 of the addendum).
Consequences: the default Colab remains API-first CPU-safe; heavy open backends activate only on audited hardware profiles; no self-approval — the registry refuses a routing where the visual architect is also the sole QC reviewer.
